- 想整体了解 → `开发总方案.md`

## 文档治理

- 方案变更必须回流到 `开发总方案.md`；进度更新到 `进度.md`；新增文档同步本索引。
- 运行时状态（.env、DB、MinIO、生产备份）不属于源码文档，不入库。
