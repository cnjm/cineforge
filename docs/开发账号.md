# 开发账号（dev account）

本地开发联调统一使用**自动种子账号**，新拉代码启动后端后自动存在，无需手工造号。

## 默认开发账号

| 项 | 值 |
|---|---|
| 手机号 | `13800000000` |
| 密码 | `CineForge@123` |
| 用户名 | `dev` |
| 角色 | `admin`（平台管理员） |

登录接口：`POST /api/auth/login` `{"phone": "13800000000", "password": "CineForge@123"}`

## 自动种子原理

- 配置键：`CINEFORGE_DEVSEED_*`（见 `cineforge-server/.env.example`），仅 **`CINEFORGE_DEVSEED_ENABLED=true` 且 phone/password 非空**时生效。
- 后端启动时按 phone 幂等查重：不存在则用与成员管理一致的规则创建（PBKDF2 120,000 次 + UUID）；已存在则跳过。
- 实现：`cineforge-server/internal/devseed/seed.go`，钩子位于 `cmd/server/main.go`。
- **红线**：生产环境必须保持 `CINEFORGE_DEVSEED_ENABLED=false`（config.yaml 默认即 false）。

## 新拉代码启动步骤（会顺带把账号造好）

```bash
cd cineforge-server
cp .env.example .env    # 按需填 CINEFORGE_DB_PASSWORD 等私有值（devseed 默认已开启）
docker compose up -d    # postgres/redis/minio
go run ./cmd/migrate -action up
go run ./cmd/server     # 启动时自动创建 dev 账号（日志：devseed: dev account created）
```

构建产物与 .env 均为 gitignored，可放心 clone 后照此操作。
