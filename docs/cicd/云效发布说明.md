## 计划内容（P6 填写）

### 产物流水线
1. checkout `cineforge-server`
2. Go `go build -o bin/cineforge-server .`（Linux amd64）
3. agent：`pip install -r agent/requirements.txt` + venv 打包
4. 上传双产物到云效产物库
5. ECS `deploy.sh`：停旧 → 换新 → systemd 拉起 → `/ready` 健康检查

### systemd 服务
- `cineforge-server.service`（Go 单体，HTTP :8080 / gRPC :8090）
- `cineforge-agent.service`（Python agent，端口占位）

### 需要你提供的真实值（P6 时）
- 云效流水线地址 / 构建机
- ECS 服务器地址与部署目录
- AccessKey / 仓库私钥（机密，不入 git）
