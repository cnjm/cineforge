# 文件与资产域契约（P3f 规范化记录）

> 以既定契约为基线（FastAPI 参考实现）：
> - `internal/storage`（归档 / 删除 / 流式读取）
> - `internal/api/file_handlers.go`（task-upload / content / playback-url / download-url / download / stream）
> - `internal/api/asset_handlers.go`（资产 CRUD / library / variant-plans / temporary-production）
> - `internal/api/project_handlers.go`：`scene-options`、`asset-tasks`、`storyboard-tasks`、`delete_project_episode`
>   （含 `hard_delete_project_episode` + `cleanup_deleted_episode_files`）
>
> 实现见 `cineforge-server/internal/storage`、`internal/service/{import_archiver,files,assets,task_generators_net}.go`、
> `internal/repository/{projects_admin_delete,task_generators_net,assets_*}.go`、`internal/api/{file,asset,task}_handlers.go`。
> 契约测试：`internal/api/{file,asset,task_generators,projects_admin}_contract_test.go`（全部通过）。
> 错误映射：全项目统一 `KeyError→404`、`PermissionError→403`、`ValueError→400`、`HTTPException` detail 逐字透传。

## P3f 决策（与用户确认）

- **真实 MinIO**（minio-go SDK），不使用预签名 URL：文件读走**服务端流式代理**，Range 语义与既定契约逐字节对齐。
- `/files/{id}/stream` 与 `/download` 用 **HMAC 文件 token**（`file-playback:` 前缀 + auth_secret），与既定契约 `_create_file_token` 字节兼容（payload json 按键排序）。
- `is_company_asset_library_file` 公司资产库兜底：文件归属不可读时若命中公司资产库文件 → 放行。
- 分集删除（`delete_files=true`）真正删除 MinIO 对象；文件行删除/操作日志终局对齐 `cleanup_deleted_episode_files` 顺序（先提交级联删除，再删对象/文件行）。

## 文件域（P3f-b）

路由前缀 `/api/files`。

### POST /files/task-upload（requireAuth，201）

- multipart：`task_id`（必填，非 UUID → 422）、`file` part（缺失 → 422 `请求体格式错误`）、可选 `file_size`。
- 手动解析 multipart（gin/binding 丢弃 part Content-Type）→ 流式上交 MinIO，不整读文件。
- 对象键 `{prefix}/{EP}/{tasktype 目录}/TASK-{id8}/V{NN}/`，文件名段含 `EP01-S001-{tasktype}-TASK-{id8}` 镜像码；`file_code {PREFIX}-{TASKTYPE}-UUID8-V{NN}`。
- 一任务多次上传布点递增（V001 → V002 …），每次一条 `files` 记录 + 幂等候选登记（`task_id + file_id` 幂等）。
- 响应：`{id, file_code, bucket, object_key, file_name, mime_type, file_size, url}`，`url = minio://{bucket}/{object_key}`。

### 读取三态

- `GET /files/{id}/content`（requireAuth）：`AuthorizedFile`（404 `File not found` / 403，公司资产库文件兜底）→ 流式读；Range 缺失 → 200 全量。
- `GET /files/{id}/stream?token=`（open，token=playback）：`Invalid playback token` / `Playback token expired` 逐字；播放用户被停用 → 401。
- `GET /files/{id}/download?token=`（open，token=download）：支持 `download_name`，Content-Disposition 用 `filename*=UTF-8''` RFC3986 编码。
- `GET /files/{id}/playback-url` / `download-url`（requireAuth）：签发 token（TTL 由 `CINEFORGE_AUTH_FILE_PLAYBACK_TTL_SECONDS` 配置，decimal 微秒截断对齐既定实现），`Cache-Control: no-store`，返回 `{url, expires_at, expires_in_seconds}`；download-url 额外回传 sanitize 后的 `file_name`（`SafeDownloadName`：`[<>:"/\\|?*\r\n]+` 折叠为 `_`，去首尾 ` ._`，[:240]）。

### Range / 416 / 媒体类型

- Range 存在且非法 → 416 `application/octet-stream` + `Content-Range: bytes */{size}`。
- 合法 Range → 206，`Accept-Ranges: bytes`、`Cache-Control: private, max-age=300`、`Vary: Range`、`Content-Range: bytes {s}-{e}/{size}`。
- `mediaTypeOf = mime_type or "application/octet-stream"`。

### 文件 token 字节兼容

```text
body = base64url_nopad(json({purpose, file_id, user_id, exp, [download_name]}))   // json 按键排序 == sort_keys=True
token = body + "." + base64url_nopad(hmac_sha256(auth_secret, "file-playback:" + body))
```

## 资产域（P3f-c）

路由前缀 `/api/assets` + `/api/projects/{id}/asset-revisions/current/scene-options`。

| 端点 | 方法 | 守卫 | 要点 |
|---|---|---|---|
| `/assets/library` | GET | auth | query `project_id`（可空，空 → 全公司）、`include_versions`；project 404 `Project not found`、403；返回资产库条目 |
| `/assets` | GET | auth | `asset_type` / `search` / `project_id` / `include_metadata` |
| `/assets` | POST | director/admin | 201 正式码分配（角色可读）；`name` 空 → 422 `name 不能为空`；`project_id` 归属校验 |
| `/assets/{id}` | GET | auth | 404 / 403 |
| `/assets/temporary-production` | POST | director/admin | 临时资产生产：未确认 assets → 400、201 + `request_id` 幂等、跨版本守卫 |
| `/assets/variant-plans` | GET/POST | 读 auth / 写 director | 创建恒 400（契约未允许前端直建变体计划），列表返回计划 |
| `/assets/variant-plans/{plan_id}` | PATCH/DELETE | director | 更新 / 退役，404 |
| `GET /projects/{id}/asset-revisions/current/scene-options` | GET | auth | 从 human 终版修正提取场景选项；403/404 |

- 资产绑定：分集详情（`GET /projects/{id}/episodes/{episode_id}`）返回 `asset_bindings`（episode_asset_bindings）。
- AssetVersion 物化接线：主/备用母版落 `asset_versions`（`data_state=final` 唯一正式下游数据源）。

## 任务生成器（P3f-d）

路由前缀 `/api/projects/{project_id}`，requireDirectorOrAdmin。

### POST /asset-tasks（201）

- 必填 query：`episode_id` + `script_version_id`（缺失 → 422 `请求体格式错误`）。
- 数据链守卫（detail 逐字，顺序对齐既定契约）：
  1. project 404 `Project not found`；分集/版本作用域不属于项目 → 404。
  2. 库存空 → 400 `当前分集没有已确认正式资产，不能进入任务阶段。`
  3. 任一正式资产未确认（tier-1 `assets_not_confirmed` 短路）→ 400 `当前分集没有已确认正式资产，不能进入任务阶段。`
  4. 资产缺专用 Prompt Skill → 409 `以下资产尚未经过专用 Prompt Skill：C01 小明。请先补齐资产 Prompt。`
  5. 无人 final revision → 400 `当前分集没有已确认资产或可用于兼容回填。`
- **行锁幂等**：`SELECT ... FROM tasks ... FOR UPDATE` 锁项目行，`task_idempotency_key`（身份字段规范化 JSON + SHA-256）已存在 → 直接返回既有任务（200/201 语义同首建）。
- 逐资产生成 1 条 `task_type='asset'` 任务 + `variant_plan`/`variant_kind` 绑定。

### POST /storyboard-tasks（201）

- 同为查询必填 + 行锁幂等；父分镜 10-15 秒硬校验；为每个父分镜生成 1 条任务。
- 镜中分镜（子分镜）生成到 task_prompts（storyboard 引用），不单独开任务。

## 分集删除文件清理（P3f-e）

### DELETE /projects/{id}/episodes/{episode_id}（requireDirectorOrAdmin）

- body：`confirm_episode_code`（不匹配 → 400 `删除确认不匹配，请输入分集编号 {code}。`）、`delete_files`（默认 true）。
- 级联删除 + 文件清理分两段（对齐既定契约）：

**第一段（事务内）**：级联删除（脚本/版本/分镜/任务/输出/提交/Agent run/workflow/资产绑定…）+ `files` 的 `task_id/episode_id` 无条件置空；仅当 `delete_files=true` 且存在候选文件时，做**引用计数**（`script_versions.source_file_id`、`asset_versions.file_id|preview_file_id`、`image_outputs/video_outputs/final_outputs.file_id`）得出 `clean` 与 `shared`；操作日志 `detail.file_cleanup` 记为 `{status: pending|not_requested, objects}`。

**第二段（提交后）**：对 `clean` 逐项 `storage.Remove(bucket, object_key)`（幂等）；成功 → 删除对应 `files` 行；失败 → 记为失败（文件行保留，`pending_retry` 可重试）；`shared` 不触碰对象；最后把操作日志 `detail.file_cleanup` 回填为最终计数形状。

### file_cleanup 响应形状（恒返回，对齐既定契约）

```json
{
  "succeeded": 1, "failed": 0, "shared_retained": 0, "pending_retry": 0,
  "failed_objects": [],
  "shared_objects": []
}
```

- `shared_objects[*].reason = "仍被项目级或其他分集数据引用"`；`failed_objects[*]` 带 `error`。
- `delete_files=false` → 只级联删除，文件行保留（task_id/episode_id 已置空），计数全 0。
- 测试：`TestDeleteEpisodeKeepsFilesWhenDeleteFilesFalse` / `SharedFileRetained` / `CleansMinIOFiles`（真实 MinIO 闭环）。
