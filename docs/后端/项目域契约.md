# 项目域契约（P3d 规范化记录）

> 以既定契约为基线：projects / production_brief / agents 的 agent-runs 子路由（FastAPI 参考实现）。
> 实现见 `cineforge-server/internal/api/project_handlers.go`、`internal/service/{projects,projects_episodes,breakdown,script_parse}.go`、`internal/repository/projects*.go`。
> 契约测试见 `internal/api/project_contract_test.go`（全部通过）。
> 错误映射：`KeyError→404`、`PermissionError→403`、`ValueError→400`、`HTTPException` detail 逐字透传。404/403 顺序对齐既定契约 `get_project`：**存在性先（404 "Project not found"），权限后（403 "Project permission denied"）**。

## 端到端链路与作用域

- 四层数据链：`AgentRun output_json` → `ArtifactRevision normalized` → 人工 `final` → 下游。
- 拆解数据最小作用域：`project_id + episode_id + script_version_id`；前端只能读规范 `BreakdownRead.view`，禁止直读 `AgentRun.output`。

## Import（POST /api/projects/import）

- 鉴权：director/admin。
- 请求：multipart/form-data（raw 体 + query 参数）。`filename` 缺省 `script.txt`，`episode_no` 缺省取剧本内标题，`confirm_existing_episode_version=true` 确认覆盖上个版本。
- 校验顺序与文案逐字：
  - 400 `请填写项目名称或选择带文件名的剧本文件。` / `请填写项目缩写。`
  - 400 `剧本导入仅支持 .txt、.md、.docx 文件。`
  - 413 `剧本文件不能超过 20MB。`
  - 400 `剧本文本包含过多无效控制字符，请检查文件编码或内容。`（Go 按 rune 计数，见 `script_parse.go` CJK 修正）
  - 400 `剧本正文不能超过 200 万字符。`
  - 400 `剧本文件未解析出有效文本，请检查文件内容或格式。` / `文本文件编码无法识别，请使用 UTF-8 或 GB18030 编码。`
  - 400 DOCX：`DOCX 文件包含过多内部条目，已拒绝解析。` / `DOCX 文件包含不安全的内部路径。` / `DOCX 解压后内容超过 50MB 限制。` / `DOCX 正文结构超过 10MB 限制。` / `DOCX 文件结构无效或缺少 word/document.xml。`
- **P3d 边界**：new-project 导入时生产归档器（`DefaultArchiver`）恒失败 → `503 剧本原文件归档失败，未创建正式剧本版本，请稍后重试。`（P3f 接入 MinIO 后消除）
- 成功：`201 ProjectRead`（含 `latest_import`）。

## 五步拆解（POST /api/projects/{project_id}/breakdown-steps/{step}）

| 路由 step | agent_type | 既定 step |
|---|---|---|
| `reading` | `script_breakdown` | `script_reading` |
| `assets` | `script_breakdown` | `asset_extract` |
| `prompts` | `script_breakdown` | `asset_prompt_generation` |
| `segmentation` | `script_segmentation` | `script_segmentation` |
| `storyboard` | `script_breakdown` | `storyboard_breakdown` |

- 请求 query：`episode_id`、`script_version_id`（缺省自动解析单分集）。
- 前置校验（顺序）：
  - 400 `未知的拆解步骤：{step}`
  - 404 `Project not found`
  - 403 `Project permission denied`
  - 400 `项目暂无剧本文本，请先导入剧本。`
- **执行留 P4**：当前返回 `202 AgentRunRead（status=queued）`，落 `workflow_runs` + `agent_runs` 行 + `breakdown_step_created` 操作日志，实际 Agent 执行由 agent 子模块（P4）消费。
- 幂等：同作用域存在 `queued/running` 同 agent_type 的顶层层级运行 → 直接返回同一 run（202，不重复提交）。
- **闸口文案（逐字）**：
  - `围读结果已确认，不能重复运行剧本围读。`（409）
  - `请先确认围读结果，再运行资产拆解。`（400）
  - `资产拆解结果已确认，当前剧本版本不能重复运行资产拆解。`（409）
  - `请先确认资产拆解结果，再生成资产提示词。`（400）
  - `请先确认围读结果，再运行脚本段拆分。`（400）
  - `请先人工确认资产清单，再运行脚本段拆分。`（400）
  - `以下资产尚未经过专用 Prompt Skill：{names}。请先补齐资产 Prompt。`（409）
  - `脚本段已经确认，当前剧本版本不能重复运行脚本段拆分。`（409）
  - `本集分镜任务已经分发，不能再次运行分镜拆解。请先处理现有任务或建立新的分集。`（409）
  - `请先运行脚本段拆分并确认脚本段，再运行分镜拆解。`（400）
  - `已确认脚本段缺少 dialogue_lines：{names}。请重新运行并人工确认脚本段拆分。`（409）
  - `请先人工确认正式资产，再运行分镜拆解。`（400）

## 拆解草稿（/breakdowns/current）

- `GET`：200 `BreakdownRead` 或 `null`（无匹配作用域）。读侧用 `overlayAuthoritativeReading` 回填正式 `reading_report`/`reading_review_state`。
- `POST`（保存）：201 `BreakdownRead`；乐观锁冲突 → 409 `拆解草稿已被其他保存更新（当前版本 v{n}，你编辑的是 v{m}）。请刷新后重试，避免覆盖他人修改。`
- 保存校验夹（`validateBreakdownViewForSave`）：`schema_version`、`reading_review_state`/`asset_review_state` 两个 map 必须同时存在且状态合法。
- **显式人工确认**（`explicitHumanConfirmation`）：`status=confirmed` + `confirmed_revision_id` 为 null + `confirmation_mode=human_confirmed` → 保存时生成 `agent/system/human` 三级 `reading_report` revision（human 落 `data_state=final`），`confirmed_revision_id` 由服务回填并写回 view。
- `buildBreakdownContent` 保留 `reading_report`/`reading_review_state`/`asset_review_state` 以承载检查点；`episode_id`/`script_version_id` 存字符串（非指针）。

## 分集

- `GET /projects/{id}/episodes` → 200 数组 `EpisodeItem`；`breakdown_status` 链：`script_imported`（待围读）→ `reading_confirmed` → `asset_draft`/`asset_saved` → `breakdown_confirmed` → `storyboard_ready` → `production`；profile 哈希或 episode brief 变更 → `outdated`。围读完成后 `reading_report.summary` 回填 `summary`。
- `GET /projects/{id}/episodes/{episode_id}` → 200 `EpisodeDetail`（版本列表 + 空 `assets` 绑定，P3f 补资产）。幽灵分集 → 404 `Episode not found`。
- `GET /projects/{id}/episodes/{episode_id}/versions/{version_id}` → 200 `ScriptVersionDetail`（正文）。缺省第一个版本标 `is_current`。
- `PATCH /projects/{id}/episodes/{episode_id}/production-brief`（director/admin）→ 200 校验后的简报 JSON。

## Dashboard 项目健康度

- `GET /projects/{id}/dashboard` → 200 `DashboardSummary`：`storyboard_count / asset_count / task_count / completed_task_count / overdue_task_count / completion_rate / recent_activity`。
- 启用缓存的键 `cineforge:project-dashboard:v1:{project_id}`（`project_status_cache_ttl_seconds`）——P3g 接 Redis；当前直查。

## agent-runs

- `GET /api/agent-runs?project_id=&limit=&cursor=` → 200 分页（limit 缺省 50）。任意登录用户。
- `GET /api/agent-runs/{run_id}` → 200 `AgentRunRead`；非项目成员 → 403 `Project permission denied`（read 权限）或 `Agent run permission denied`。

## 其他

- `GET /api/production-brief/catalog` → 200 brief catalog + `styles`（from `productionbrief` 包）。
- `GET /projects/{id}/script-segments?episode_id=` → 200 数组（任意登录用户，需项目读权限）。
- `POST /api/projects` → 201；`PATCH /api/projects/{id}` → 200。项目号 `project_prefix` 唯一；已导剧本后缩写锁定（400 `项目已导入剧本，项目缩写已锁定；修改编号体系需使用专用迁移流程。`）。
- 脚本解析：`.txt/.md` 按 UTF-8（BOM 容错）→ GB18030；`ParserName` → `plain_text_v1|markdown_text_v1|docx_xml_v1`；`DetectScriptLanguage` → `zh|zh-mixed|multilingual|latin|unknown`。
