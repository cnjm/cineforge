# CineForge · 环境变量与配置项说明

> 所有环境相关值均以占位符形式存放于各仓库根目录 `.env.example`，实际值由你填写。
> 规则：**配置是唯一可变入口，代码不做硬编码。**

## 前端 cineforge-h5

见 `cineforge-h5/.env.example`（P1 提供）：

| 变量 | 占位 | 说明 |
|---|---|---|
| `VITE_API_BASE` | `https://cine-forge-server.cnjm.top` | 后端 API 域名 |
| `VITE_GO_API_BASE` | `https://cine-forge-server.cnjm.top` | （如复用）Go 网关域名 |

## 后端 cineforge-server

见 `cineforge-server/.env.example`（已就位）：

| 变量 | 占位/默认 | 说明 |
|---|---|---|
| `CINEFORGE_DB_DSN` | `postgres://cineforge:CHANGE_ME@127.0.0.1:5432/cineforge` | 单库 DSN |
| `CINEFORGE_SERVER_DOMAIN` | `cine-forge-server.cnjm.top` | 后端域名 |
| `CINEFORGE_WEB_DOMAIN` | `cine-forge.cnjm.top` | 前端域名（CORS 放行用） |
| `CINEFORGE_MINIO_BUCKET` | `cineforge-assets` | MinIO bucket（未开通，占位） |
| `CINEFORGE_HERMES_ADDR` | `http://localhost:8642` | Hermes Agent 网关 |
| `CINEFORGE_AGENT_ADDR` | `http://localhost:8091` | Python agent 子模块 |
| `CINEFORGE_HTTP_ADDR` / `CINEFORGE_GRPC_ADDR` | `:8080` / `:8090` | 监听地址 |
| `CINEFORGE_DEVSEED_ENABLED` | `false` | 开发账号自动种子开关（生产必须 false） |
| `CINEFORGE_DEVSEED_PHONE` / `CINEFORGE_DEVSEED_PASSWORD` | `13800000000` / `CineForge@123` | 开发账号手机号/密码（详见 [开发账号.md](开发账号.md)） |
| `CINEFORGE_DEVSEED_USERNAME` / `CINEFORGE_DEVSEED_DISPLAY_NAME` / `CINEFORGE_DEVSEED_ROLE` | `dev` / `开发账号` / `admin` | 开发账号默认值，可不填 |

## 云效 / ECS（P6 铺设，先占位）

云效流水线变量、ECS 地址、AccessKey 等统一占位，写在 `docs/cicd/` 与 `.env.example` 中，不落任何真实密钥进 git。
